HIMALAYA AIRLINES - KOSELI ONBOARD MENU (offline package from OBS)
===================================================================

This folder was downloaded from OBS > QR Menu > "Download offline package".
It is the menu exactly as the administrator set it up in OBS, for use on a
laptop with no internet (phones join the laptop's Wi-Fi / hotspot).

QUICK START
  1. Double-click  start-server.bat
  2. A QR page opens in your browser. Show it, print it, or scan it.
  3. Any phone on the SAME Wi-Fi can now open the menu.

  First time only: if phones can't open the page, double-click
  fix-network-access.bat (click "Yes" for admin). It:
    - opens TCP ports 8080-8089 in Windows Firewall
    - switches your Wi-Fi from "Public" to "Private" (asks first)
    - turns off any old rules that block Python

UPDATING THE MENU
  Do not edit files here. Change items, photos and prices in OBS (QR Menu,
  administrator only), then download a new offline package and replace
  this folder.

REQUIREMENTS
  Windows with Python 3.8+ (python.org, tick "Add python.exe to PATH").
  No extra packages needed.

FILES
  start-server.bat         start the menu server
  fix-network-access.bat   one-time firewall / network fix (admin)
  server.py                the web server (Python standard library only)
  qrgen.py                 built-in QR code generator (no dependencies)
  public\index.html        the menu (generated by OBS)
  public\qr.html           the printable QR page
  public\assets\media\     photos and posters

ADVANCED
  python server.py --port 9000        use a different port
  python server.py --no-browser       don't open the QR page on start
  Open the menu in Chinese directly with:  http://<ip>:8080/?lang=zh
